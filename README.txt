ひとかぞえ V1.1（3時間計測向け）

GitHubでの更新:
既存の satonowa-people-counter リポジトリに、このZIP内の index.html をアップロードしてコミットしてください。
既存の index.html と同じ名前のまま差し替えます。ZIP自体をアップロードしないでください。
公開URL: https://satonowa311-coder.github.io/satonowa-people-counter/

追加機能:
画面スリープ防止（対応ブラウザのみ）、計測経過時間、通過時と約10秒ごとの端末内保存、映像・AI停止時の警告、計測途中でページが閉じた際の再開案内。
V1と同じ端末の保存キーを使用するため、同じブラウザ・同じURLならV1の集計を引き継ぎます。

計測時の注意:
・Chrome（Android）またはSafari（iPhone）で公開URLを開いてください。
・スリープ防止の表示が「有効」であることを確認してください。
・計測中はアプリ画面を開いたままにし、充電に余裕を持たせ、端末の発熱に注意してください。
・スリープ防止は端末の省電力機能・発熱・OS判断による停止を防ぐ保証ではありません。
・3時間連続稼働は実機未検証です。事前に15分以上のテストを推奨します。
